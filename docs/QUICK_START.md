# 🚀 Quick Start Guide - MIKE AI Agent

## Get Running in 2 Minutes

### Step 1: Download
1. Go to https://github.com/robertfairforest23-byte/ai-agent-platform-complete
2. Click "Code" → "Download ZIP"
3. Extract the folder anywhere

### Step 2: Setup
Double-click `setup.bat` and wait for it to complete.

### Step 3: Run
Choose your preferred mode:
- **Text Mode**: Double-click `run_mike.bat`
- **Voice Mode**: Double-click `run_mike_voice.bat`

## Troubleshooting

**Python not found**
- Install Python 3.9+ from python.org
- Make sure to check "Add Python to PATH"

**"Module not found" errors**
- Delete the `venv` folder
- Run `setup.bat` again

**Microphone not working**
- Check Windows Sound Settings
- Use text mode instead

**Tasks not saving**
- Check if `data` folder exists
- Verify permissions on `data/tasks.json`
